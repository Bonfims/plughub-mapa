Como ler o mapa

Uma tela só para dois níveis: a arquitetura (quem fala com quem) e os dados (que tabelas cada módulo guarda). Os módulos estão em camadas, de quem recebe o cliente até quem mede a qualidade.

clique num módulo
acende só o que ele toca e abre a ficha: o que faz, quem chama, o que publica e lê, o que ele guarda e onde tomar cuidado
Arquitetura / Dados (1 · 2)
em Dados, cada módulo se abre nas tabelas que é dono; clique numa tabela para ver campos e relações
Jornada (J)
passo a passo do caminho de uma mensagem, do cliente até o relatório
Ligações
liga e desliga cada tipo de linha: HTTP, Kafka, Redis, A2A·MCP, infra e dados
clique numa faixa
abre a descrição do grupo (Borda, Núcleo, Domínio…)
/ · F · Esc
busca · enquadrar · voltar

Ponto vermelho no canto de um módulo: 8 ou mais outros módulos o chamam. “?” : status incerto.
Linha tracejada de dados é relação curada, que o banco não declara. Em tabela, REL é relação curada e FK é chave estrangeira declarada.

Fontes: documento de integração dos módulos (2026-11-05) e anotações do time; fichas de módulos do mapa de módulos; schema real dos bancos do demo (DER); dono de cada tabela conferido no código.
